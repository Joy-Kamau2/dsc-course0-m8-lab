# Aviation Accident Analysis

Project Overview

This project analyzes aviation accident data using Python and Pandas to understand patterns in accident severity, injuries, aircraft damage, weather conditions and phases of flight.

Objectives

- Clean and prepare the aviation accidents dataset.
- Explore factors associated with serious and fatal injuries.
- Compare injury patterns across aircraft makes and models.
- Present findings using data visualizations.

Tools Used

- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Jupyter Notebook

Key Findings

- Injury severity varies across aircraft makes and models.
- Weather conditions and the phase of flight are useful factors to examine when studying accident outcomes.
- Aircraft models with few recorded accidents should be interpreted carefully.
- Accident records alone cannot determine overall aircraft safety without considering factors such as flight frequency.
